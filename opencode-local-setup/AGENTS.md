# AGENTS.md

Проект: курсовая GameAI на Java + jMonkeyEngine.
Документация актуализирована: 23.11.2026.

Цель: NPC через локальную Phi-3.5-mini ONNX генерирует игровые режимы по текстовому запросу игрока.

## Главные правила

- LLM не управляет сценой, физикой или памятью игры напрямую.
- LLM возвращает только строгий JSON GameModeSpec.
- Любой ответ LLM считается недоверенным: parse -> validate -> normalize -> apply.
- `generate()` нельзя вызывать в render-потоке jME.
- Модель загружается один раз при старте и переиспользуется.
- Перед применением нового режима старый режим полностью очищается.
- Для разработки используем MockLocalLlm, реальную Phi включаем отдельным флагом.
- Текущий `GameModeGenerator` делает максимум 2 попытки (`MAX_ATTEMPTS = 2`).
- Survival и collect пока являются сгенерированными спеками и кубами, а не играбельными режимами.

## Память и документация

- `opencode-local-setup/PROJECT_MEMORY.md` — краткое актуальное состояние проекта.
- `план.txt` — долгосрочный план и целевая архитектура.
- `план-на-2-недели-по-5-часов.txt` — основной журнал подтверждённого прогресса.
- `java-файлы-описание.txt` — назначение текущих исходников.
- `инструкция-по-этапам.txt` — подробные шаги следующих этапов.
- `метрики.txt` — фактические измерения загрузки и генерации.
- Перед перерывом: `/save-context`. После перерыва: `/resume`.
- Долгие сессии не требуют пересоздания: контекст сжимается автоматически (`compaction` в `opencode.jsonc`).
- После подтверждённого результата обновлять план с журналом и PROJECT_MEMORY; не отмечать невыполненное как готовое.
